# Lorestani Cat Disc

A Minecraft Fabric 1.21.11 mod project that adds a jukebox disc named **Lorestani Disc** and a playful cat event.

## Important audio note

The requested song is commercially copyrighted and the discovered online sources do not grant redistribution rights. This repository therefore includes a placeholder `lorestani.ogg` marker and does not redistribute the song. Replace it with an audio file you are licensed to distribute.

The phrase sound is also represented as a placeholder marker because the discovered meme/soundboard sources do not clearly grant redistribution rights. Replace `phrase.ogg` with a sound you are licensed to distribute.

## Intended behavior

- Place the Lorestani Disc in a jukebox.
- The jukebox references `lorestani_cat_disc:lorestani`.
- Nearby cats are teleported to the player, given a 20-second airborne dance animation, and then the phrase is played.

## Build

Use Java 21 and Gradle with the Fabric 1.21.11 template. The exact Fabric API version is pinned in `gradle.properties`.

This repository currently contains the source scaffold and resource placeholders. A compiled JAR is not included until the project is built in a Java/Gradle environment.
